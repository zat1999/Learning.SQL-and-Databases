# 01 - SQL Basics

The [BasicQuery.sql](BasicQuery.sql) script is a first exercise using Microsoft SQL Server. It creates a practice database and `Products` table, inserts three rows, then selects products priced above 100.

## Concepts

- `CREATE DATABASE` and `USE`
- `CREATE TABLE`, data types, primary keys, and constraints
- `INSERT INTO`
- `SELECT`, `WHERE`, and `ORDER BY`

## Run

Open the script in SQL Server Management Studio or Azure Data Studio and execute it against a SQL Server instance. The script creates a database named `SQLExamPractice`; make sure you have permission to create databases and that the name does not conflict with an existing database.
