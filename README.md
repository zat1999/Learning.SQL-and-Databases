# SQL Learning Journey

A practical record of my SQL learning journey, from foundational queries to complete projects. This repository contains tutorials, hands-on projects, and notes that I can revisit and share as I build my skills.

## Repository structure

```text
.
├── datasets/      # Sample data and notes about its source
├── notes/         # Concepts, useful patterns, and learning notes
├── projects/      # End-to-end SQL projects
└── tutorials/     # Small exercises organized by topic
```

## Learning roadmap

- [x] Create a database and table, insert rows, and query the results
- [x] Filter and sort data; use aliases and expressions
- [x] Aggregate data with `GROUP BY` and `HAVING`
- [x] Combine tables with joins
- [ ] Use subqueries, common table expressions, and window functions
- [ ] Build projects that apply these concepts to realistic questions

## Getting started

The first tutorial is [`BasicQuery.sql`](tutorials/01-basics/BasicQuery.sql). It uses SQL Server syntax, including `GO`, and creates a small product table with sample rows.

Run scripts only in a practice database or other environment where you are comfortable creating and changing data. Add a short README to each new project explaining its goal, dataset, SQL dialect, and how to run the scripts.

## SQL dialect

The current example targets Microsoft SQL Server. Future scripts may use other database systems; each tutorial or project should identify its SQL dialect when syntax differs.
